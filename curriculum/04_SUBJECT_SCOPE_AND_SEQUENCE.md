# 04 — Subject Scope and Sequence

> **Project context:** K–12 Learning App Suite with Foundation Academy (K–5), Bridge Academy (6–8), and Scholar Academy (9–12). The platform is a thinking-development and retention platform, not a video/flashcard library. Every curriculum artifact must support the core loop: **Teach → Break Down → Think → Discuss → Interpret → Prove → Practice → Retrieve → Space → Reflect → Adapt → Apply**.

## Purpose

This document defines how each subject progresses across K–12. It complements the grade-by-grade scope by looking vertically through each discipline.

## Locked Core Pillars

Every syllabus, unit, lesson, assessment, activity bank, and review item must support the locked core pillars:

1. Standards-Aligned Curriculum
2. First-Principles Problem Solving
3. Critical Thinking
4. Discussion & Academic Dialogue
5. Interpretation
6. Evidence-Based Reasoning
7. Metacognition
8. Retrieval + Spaced Retention
9. Inquiry-Based Learning
10. Computational + Systems Thinking
11. Project-Based Application
12. Adaptive Mastery + Feedback
13. Fun + Motivation
14. Accessibility + Inclusive Learning
15. Safe Child-Centered Design

## ELA / Reading

| Grade Band | Scope | Key Outputs |
|---|---|---|
| K–2 | Phonological awareness, phonics, fluency, vocabulary, read-aloud comprehension | Decode, retell, answer who/what/why, identify story parts |
| 3–5 | Main idea, theme, inference, text structure, point of view, evidence | Short constructed responses, evidence selection, summaries |
| 6–8 | Literature analysis, nonfiction argument, rhetoric, media literacy, source use | CER paragraph, debate response, theme analysis |
| 9–12 | Literary analysis, rhetoric, research, synthesis, advanced argument | Essays, research papers, presentations, capstone writing |

## Writing

| Grade Band | Scope | Key Outputs |
|---|---|---|
| K–2 | Letters, sentences, drawing/writing, opinion, narrative basics | Labeled picture, sentence, short story |
| 3–5 | Paragraphs, opinion, informational, narrative, revision | Multi-paragraph writing, source-supported short response |
| 6–8 | Thesis, evidence, transitions, research, peer review | Argument essay, explanatory essay, research report |
| 9–12 | Rhetorical control, advanced research, synthesis, portfolio | Literary analysis, research paper, policy brief, capstone |

## Math

| Grade Band | Scope | Key Outputs |
|---|---|---|
| K–2 | Counting, operations, place value, shapes, measurement | Number models, visual solutions, simple word problems |
| 3–5 | Multiplication/division, fractions, decimals, geometry, data | Multi-step problems, models, explanations |
| 6–8 | Ratios, rational numbers, expressions, equations, functions, statistics | Strategy explanations, equation solving, graph interpretation |
| 9–12 | Algebra, geometry, advanced functions, statistics, finance | Proof, modeling, data analysis, real-world problem solving |

## Science

| Grade Band | Scope | Key Outputs |
|---|---|---|

| 6–8 | Earth systems, life science, physical science, engineering design | Models, lab logs, systems explanations |
| 9–12 | Biology, chemistry, physics, environmental science | Lab reports, data interpretation, model-based explanations |

## MVP Subject Priority

For MVP, prioritize:

1. ELA / Reading
2. Math
3. Science
4. Social Studies

Writing, CS, SEL, health/PE, and arts should be integrated into these first four before becoming standalone tracks.
