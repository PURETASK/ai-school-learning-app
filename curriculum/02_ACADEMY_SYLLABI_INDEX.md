# 02 — Academy Syllabi Index

> **Project context:** K–12 Learning App Suite with Foundation Academy (K–5), Bridge Academy (6–8), and Scholar Academy (9–12). The platform is a thinking-development and retention platform, not a video/flashcard library. Every curriculum artifact must support the core loop: **Teach → Break Down → Think → Discuss → Interpret → Prove → Practice → Retrieve → Space → Reflect → Adapt → Apply**.

## Purpose

This document defines the three academy master syllabi and the rules for producing grade/course syllabi under each academy. It prevents the K–5, 6–8, and 9–12 experiences from feeling like the same app with different labels.

## Locked Core Pillars

Every syllabus, unit, lesson, assessment, activity bank, and review item must support the locked core pillars:

1. Standards-Aligned Curriculum
2. First-Principles Problem Solving
3. Critical Thinking
4. Discussion & Academic Dialogue
5. Interpretation
6. Evidence-Based Reasoning
7. Metacognition
8. Retrieval + Spaced Retention
9. Inquiry-Based Learning
10. Computational + Systems Thinking
11. Project-Based Application
12. Adaptive Mastery + Feedback
13. Fun + Motivation
14. Accessibility + Inclusive Learning
15. Safe Child-Centered Design

## Academy Syllabus Structure

Every academy syllabus must include:

- Academy purpose.
- Student developmental profile.
- UX principles.
- Subjects/courses included.
- Thinking skills emphasis.
- Assessment style.
- Memory Vault strategy.
- Project/capstone style.
- Parent/teacher reporting needs.
- Safety and communication limits.
- MVP subset.
- Expansion roadmap.

## Foundation Academy Syllabus

### Grade Range

Kindergarten through Grade 5.

### Purpose

Build foundational reading, writing, math, curiosity, habits, emotional regulation, early civic understanding, guided inquiry, and basic computational logic.

### Subject Coverage

| Subject | K–5 Curriculum Role |
|---|---|
| ELA / Reading | Phonological awareness, phonics, vocabulary, fluency, comprehension, text evidence. |
| Writing | Sentences, paragraphs, narratives, opinion, informational writing, revision. |
| Math | Number sense, operations, place value, fractions, measurement, geometry, data. |
| Science | Observation, life science, Earth science, physical science, engineering habits. |
| Social Studies | Family, community, maps, civics, cultures, early history. |
| Health / PE | Movement, wellness, hygiene, safety, emotions. |
| Arts / Music | Creative expression, rhythm, visual communication. |
| Computer Science | Sequencing, patterns, algorithms, digital citizenship. |
| SEL / Life Skills | Kindness, responsibility, persistence, collaboration. |

### UX Rules

- Short lessons.
- Big buttons.
- Read-aloud support.
- Visual manipulatives.
- Guided play.
- Parent-friendly dashboards.
- No public chat.

### Assessment Style

Assessment should be low-pressure, visual, guided, and feedback-rich. Use short checks, oral/read-aloud options, drag-and-drop, matching, drawing prompts, and simple explain-your-thinking tasks.

## Bridge Academy Syllabus

### Grade Range

Grade 6 through Grade 8.

### Purpose

Build middle-school independence, academic discipline, study habits, evidence use, structured discussion, research, pre-algebra/algebra readiness, lab thinking, and abstract reasoning.

### Subject Coverage

| Subject | 6–8 Curriculum Role |
|---|---|
| ELA | Literature, nonfiction, theme, argument, rhetoric, vocabulary. |
| Writing | Thesis, paragraphs, argument, informational writing, research. |
| Math | Ratios, rational numbers, expressions, equations, geometry, statistics. |
| Science | Earth systems, life science, physical science, engineering investigations. |
| Social Studies | Ancient/medieval/world history, U.S. foundations, civics, geography. |
| Computer Science | Algorithms, Python intro, data, cybersecurity basics, AI literacy. |
| Health / PE | Wellness, mental health, relationships, safety. |
| Arts / Media | Design, media literacy, presentation. |
| SEL / Study Skills | Time management, organization, teamwork, digital citizenship. |

### UX Rules

- Quest map and skill trees.
- Study planner.
- More independence than Foundation.
- Structured debate and evidence tasks.
- Safe class discussion only after moderation controls.

## Scholar Academy Syllabus

### Grade Range

Grade 9 through Grade 12.

### Purpose

Build high-school course mastery, credits/transcript-style progress, research writing, labs, mathematical proof/reasoning, civics/economics, career/college readiness, portfolio evidence, and capstone work.

### Course Families

| Family | Courses |
|---|---|
| English | English 9, English 10, American Literature, World/British Literature, Advanced Composition. |
| Math | Algebra I, Geometry, Algebra II, Precalculus, Statistics, Financial Math. |
| Science | Biology, Chemistry, Physics, Environmental Science, Earth/Space Science. |
| Social Studies | World History, U.S. History, Government, Economics. |
| CS/Career | CS Foundations, Python, Web Design, Game Design, Digital Media, Career Readiness. |
| Wellness/Arts | Health, PE, Arts, Media. |
| Capstone | Research project, portfolio, presentation, real-world application. |

### UX Rules

- Course dashboard.
- Credit-style progress.
- Portfolio and capstone artifacts.
- Rubric-based scoring.
- More mature tone.
- No childish reward visuals.

## Academy Syllabus Acceptance Criteria

A complete academy syllabus must:

- Define grade range and user needs.
- Include all required subjects/courses.
- Define UX rules for the age band.
- Explain assessment and Memory Vault rules.
- Define project/application model.
- Identify MVP content and later expansion.
- Include safety and accessibility notes.

## Universal Review Checklist

Before this document is marked **Approved**, verify that it:

- Aligns to the three-academy structure.
- Supports the full learning loop, not just passive content.
- Identifies MVP scope versus later expansion.
- Includes implementation rules Codex can follow.
- Includes content QA expectations.
- Includes accessibility and child-safety considerations where relevant.
- Connects to standards tags, thinking skill tags, Memory Vault review, mastery bands, and parent/teacher reporting.
- Avoids scope creep by clearly naming what is out of scope for MVP.

## Status Labels

Use these workflow labels for all content artifacts referenced here:

| Status | Meaning |
|---|---|
| `planned` | Artifact exists in the backlog only. |
| `drafting` | Writer/curriculum designer is creating first draft. |
| `needs_review` | Draft is ready for academic/product review. |
| `needs_revision` | Review found required fixes. |
| `approved` | Artifact is ready for app implementation. |
| `implemented` | Artifact exists in the repo/app. |
| `tested` | Artifact has passed QA checks. |
| `published` | Artifact is live or release-ready. |
| `archived` | Artifact is deprecated but preserved for history. |
