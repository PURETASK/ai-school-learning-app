# 03 — K–12 Scope and Sequence

> **Project context:** K–12 Learning App Suite with Foundation Academy (K–5), Bridge Academy (6–8), and Scholar Academy (9–12). The platform is a thinking-development and retention platform, not a video/flashcard library. Every curriculum artifact must support the core loop: **Teach → Break Down → Think → Discuss → Interpret → Prove → Practice → Retrieve → Space → Reflect → Adapt → Apply**.

## Purpose

This document maps the complete K–12 progression. It shows what students should learn by grade and how skills become more advanced over time. It is not the full lesson library; it is the skeleton that prevents gaps, overlaps, and random sequencing.

## Locked Core Pillars

Every syllabus, unit, lesson, assessment, activity bank, and review item must support the locked core pillars:

1. Standards-Aligned Curriculum
2. First-Principles Problem Solving
3. Critical Thinking
4. Discussion & Academic Dialogue
5. Interpretation
6. Evidence-Based Reasoning
7. Metacognition
8. Retrieval + Spaced Retention
9. Inquiry-Based Learning
10. Computational + Systems Thinking
11. Project-Based Application
12. Adaptive Mastery + Feedback
13. Fun + Motivation
14. Accessibility + Inclusive Learning
15. Safe Child-Centered Design

## Scope and Sequence Rules

1. Skills should spiral from concrete to abstract.
2. Vocabulary should grow from everyday language to disciplinary language.
3. Thinking tasks should increase in independence and complexity.
4. Standards tags should be stable, but state-specific mapping can be added later.
5. Every grade should prepare for the next grade.
6. Every skill family should include Memory Vault review targets.

## Thinking Skill Progression

| Grade Band | Thinking Skill Emphasis | Student Output |
|---|---|---|
| K–2 | Notice, sort, compare, wonder, explain simply | Oral response, matching, drawing, simple sentence |
| 3–5 | Break down, model, use evidence, check answer | Paragraph, model, short explanation, visual proof |
| 6–8 | Analyze, argue, interpret, debug, map systems | CER paragraph, debate response, investigation log |
| 9–12 | Evaluate, synthesize, model, defend, transfer | Essay, proof, lab report, research, project/capstone |

## Memory Vault Progression

| Grade Band | Review Focus | Review Style |
|---|---|---|
| K–2 | Letter sounds, sight words, number facts, vocabulary | Audio/visual, matching, quick recall |
| 3–5 | Multiplication facts, key vocabulary, reading strategies, science concepts | Short answer, explain-it-back, mixed practice |
| 6–8 | Ratios, equations, evidence rules, vocabulary, systems diagrams | Mixed review, error analysis, concept maps |
| 9–12 | Formulas, definitions, evidence frameworks, historical patterns, lab concepts | Application, proof, essay planning, data interpretation |

## MVP Scope Sequence

The MVP starts in Grade 3, Grade 6, and Grade 9 because these grades test three different curriculum modes:

- Grade 3: foundational independence.
- Grade 6: middle-school transition.
- Grade 9: high-school course structure.
