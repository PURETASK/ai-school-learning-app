# K–12 Curriculum Inventory Pack v2

This pack is the expanded and reviewed curriculum-control layer for the K–12 Learning App Suite.

> **Project context:** K–12 Learning App Suite with Foundation Academy (K–5), Bridge Academy (6–8), and Scholar Academy (9–12). The platform is a thinking-development and retention platform, not a video/flashcard library. Every curriculum artifact must support the core loop: **Teach → Break Down → Think → Discuss → Interpret → Prove → Practice → Retrieve → Space → Reflect → Adapt → Apply**.

## What Changed in v2

The 20 curriculum inventory documents were expanded from starter indexes into production-control documents with:

- Clear purpose and scope.
- Required fields and schemas.
- MVP priorities.
- Acceptance criteria.
- QA checklists.
- Codex implementation rules.
- Content governance and status labels.
- Detailed tables for syllabi, units, lessons, assessments, Memory Vault, rubrics, reteach, and challenge paths.
