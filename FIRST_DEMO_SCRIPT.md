# First Demo Script

## Demo Objective

Show that the app can teach one complete lesson from start to finish and preserve learning state.

## Recommended Demo Lesson

```txt
FA-G3-MATH-U1-L1 — Multiplication as Equal Groups
```

## Demo Steps

1. Open Student Dashboard.
2. Confirm student displays as Grade 3 Foundation Academy.
3. Click today's lesson.
4. Move through lesson sections.
5. Answer quiz questions.
6. Submit quiz.
7. Show feedback and answer explanations.
8. Show mastery score and mastery band.
9. Show Memory Vault items scheduled for Day 1, 3, 7, 14, and 30.
10. Open Parent Dashboard.
11. Show completed lesson, quiz score, weak skills, and suggested support.

## Demo Success Criteria

The demo succeeds if a viewer can understand:

- What the student learned
- How they practiced it
- How they were assessed
- What they need to review
- What the parent sees
- How this proves the learning loop
