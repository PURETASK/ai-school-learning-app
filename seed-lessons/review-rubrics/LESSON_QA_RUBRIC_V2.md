# Lesson QA Rubric — Seed Lessons v2

Use this rubric before importing a lesson into the app.

## Required Pass Criteria

| Criterion | Pass Rule |
|---|---|
| Universal lesson flow | Includes hook, goal, mini teach, first-principles breakdown, worked example, guided practice, critical thinking, evidence task, interpretation/discussion, active practice, retrieval, feedback, mastery, review, reflection, reteach/challenge. |
| Quiz quality | At least 10 questions with mixed item types, correct answers, explanations, difficulty, and skill tags. |
| Memory Vault | At least 5 items with Day 1/3/7/14/30 schedule and failure/success actions. |
| Reteach | Misconception, simple explanation, steps, practice items, and exit criteria. |
| Challenge | At least 2 higher-order tasks that require transfer/application. |
| Safety | No unrestricted chat; discussion uses safe structured prompts. |
| Accessibility | Alt text/read-aloud/keyboard/color-independent guidance present. |
| Implementation | Clear notes for Lesson Player, quiz engine, mastery, and Memory Vault. |

## Review Labels

- PASS: Ready for MVP import.
- PASS WITH NOTES: Usable but should receive subject-matter review later.
- REVISE: Missing required structure or unsafe/unclear.
- BLOCKED: Cannot implement until schema or content problem is fixed.
