## Recommended Use

1. Review `LESSON_REVIEW_AND_POLISH_REPORT_V2.md`.
2. Validate JSON against `LESSON_JSON_SCHEMA_V2.json`.
3. Import `lessons/json/` as seed content.
4. Render `lessons/markdown/` for curriculum/content review.
5. Use CSV tables for dashboards, planning, and QA.

## Critical Rule

Answer-key files are teacher/admin/reviewer assets only. Do not expose hidden answer-key content in student mode.
